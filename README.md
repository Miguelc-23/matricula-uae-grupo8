# matricula-uae-grupo8

##Sistema de Matrícula UAE
Este sistema ha sido desarrollado para optimizar y agilizar el proceso de inscripción y selección de asignaturas de los estudiantes de la institución. La plataforma centraliza el flujo académico permitiendo un acceso seguro mediante credenciales institucionales, la consulta en tiempo real de la oferta de materias, la verificación de cupos disponibles por paralelo y el registro estructurado de créditos acumulados, garantizando así una experiencia ágil, transparente y libre de congestión durante los periodos de matriculación.

## Funcionalidades Principales
• Autenticación segura de estudiantes mediante credenciales institucionales.

• Consulta y selección interactiva de materias por semestre.

• Visualización en tiempo real de cupos disponibles por paralelo.

•Cálculo y control de créditos acumulados durante el proceso de matrícula.
